# mattaguilar.com

The built site, exactly as served. Each folder at the top is one theme of the
same page over a different photograph or record sleeve; `shared/` is the code
they have in common. `demos/` holds a working copy of each project the sleeves
open into.

This tree is generated from a private workshop repository and pushed whole,
so history here is a history of publishes, not of edits.
